# Python Learning Journey 🚀

Welcome to my personal Python development repository! This project serves as a comprehensive log of my journey into learning Python, progressing from basic syntax to logical scripting, data structuring, and practical applications relevant to engineering and software development.

Every script here represents a milestone in mastering problem-solving, error handling, and clean code principles.

---

## 📂 Repository Structure & Project Directory

The repository is organized systematically into core concepts and functional mini-projects:

### 📁 01-Core-Basics
This directory focuses on fundamental programming concepts, input/output manipulation, conditional logic, and safe error handling using `try-except` blocks.

*   **`interactive_profile.py`**: A beginner-friendly script focusing on user dynamic input processing and interactive string formatting.
*   **`smart_calculator.py`**: A continuous-loop console calculator featuring zero-division protection and operation safety guardrails.
*   **`student_grading_system.py`**: A simple score evaluator implementing boundary condition filtering ($0 \le \text{Grade} \le 100$) and multi-conditional logic branches.
*   **`fan_speed_controller.py`**: An embedded-system logic simulation that monitors ambient temperature and dynamically toggles state outputs (`Fan Off`, `Fan Low`, `Fan High`).

### 📁 02-Mini-Projects
Advanced scripts implementing complex data workflows, console menus, terminal user interfaces (TUI), data persistence loops, and localized security mechanisms.

*   **`unit_converter_tool.py`**: A multi-level dimensional conversion program handling both metric length mappings ($m \leftrightarrow cm \leftrightarrow km$) and thermodynamic transformations (Celsius $\leftrightarrow$ Fahrenheit).
*   **`secure_todo_manager.py`**: A password-protected terminal Task Manager utilizing index-based lists to perform dynamic scheduling operations (Add, View, Delete tasks).
*   **`secure_student_records.py`**: A robust console application simulating an administrative dashboard protected by authentication. It utilizes embedded lists of dictionaries to execute standard CRUD operations (Create, Read, Update, Delete) on student grades with strict structural error validation.

---

## 🛠️ Core Skills Demonstrated

*   **Error Handling:** Extensive use of `try-except` control flows to intercept `ValueError` and structural inputs, keeping programs crash-resilient.
*   **Data Structures:** Manipulation of native Python Lists and Dictionaries for structural data arrangement.
*   **Control Flow:** Implementation of infinite control loops (`while True`) with custom logical flags for dynamic state alterations.
